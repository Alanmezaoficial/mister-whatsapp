# Mister WhatsApp

Kit para construir un agente de atención por WhatsApp mediante entrevista. Ediciones nativas para Claude Code y Codex. No incluye un agente personalizado ya desplegado.

- [Guía Claude Code](docs/guia-claude.md)
- [Guía Codex](docs/guia-codex.md)

Instalación desde GitHub, ZIP o comandos manuales; pruebas offline antes de conectar proveedores. El runtime generado usa Anthropic, FastAPI y SQLite/PostgreSQL con Zernio o Meta. Consulta LICENSE y NOTICE para los avisos de redistribución.
